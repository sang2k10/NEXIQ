## Reporting a Vulnerability

The NEXIQ development team takes security and privacy seriously. If you discover a security vulnerability, sensitive data leakage, or permission escalation flaw, please report it responsibly.

### How to Report
Please **do not** report security vulnerabilities through public GitHub issues, discussions, or pull requests.

Instead, submit your report via **GitHub Private Vulnerability Reporting**:
1. Navigate to the [NEXIQ Security Advisories tab](https://github.com/sang2k10/NEXIQ/security/advisories).
2. Click **"Report a vulnerability"**.
3. Include detailed information about the vulnerability:
   - Type of issue (e.g. unauthorized buffer retention, intent redirection, IPC exposure).
   - Step-by-step reproduction instructions or a minimal proof of concept.
   - Affected Android versions and device models.
   - Potential impact on user privacy or system security.

If you are unable to use GitHub Security Advisories, contact the repository maintainer directly at the contact address listed on their GitHub profile:  
[https://github.com/sang2k10](https://github.com/sang2k10)

### Response Timeline
- **Initial Response**: Within 48 hours of receipt.
- **Triage & Assessment**: Within 7 business days.
- **Fix & Public Disclosure**: We coordinate patch releases and publish security advisories after an appropriate mitigation window.
